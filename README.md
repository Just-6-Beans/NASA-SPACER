# SPACER

An educational browser game about orbital station operations and a real Mars rover survey, inspired by the NASA Space Apps Challenge. You pick a spacecraft, crew the station, repair a relay, then choose one of NASA's rovers, Perseverance or Curiosity, and drive it across a real picture of its surroundings taken from orbit: tap points for it to drive to, watch its camera as it goes, photograph real photo spots on the way, test the ground wherever it stops, recharge when the battery runs low, and decide where the crew's base goes before the mission's ten Mars days run out.

**Real data, game rules on top.** The picture of the ground from orbit, the map heights, the places the rovers really parked (with their slopes and elevations), the photos, selfies and videos, the Gale Crater weather, the radiation, the terrain roughness and the rover power figures come from NASA (see [Rover expedition](#rover-expedition-perseverance-and-curiosity)). Station tasks, costs, other power loads, the ten-day limit and the scores are our game model, and the game labels which is which. No NASA logos are used.

Stack: Phaser 3.90 (Arcade Physics), TypeScript, Vite, HTML/CSS interface, Colyseus co-op. All art is original vector artwork generated by `scripts/gen-art.mjs` and bundled in `public/assets/`.

This is our team's entry for the NASA Space Apps Challenge 2026 challenge [Space Mission Design Game](https://www.spaceappschallenge.org/2026/challenges/space-mission-design-game/). It is a fresh build of Spacer. The original prototype is in [Space-Mission-Design-Game](https://github.com/Just-6-Beans/Space-Mission-Design-Game).

## Set up a device

```bash
git clone https://github.com/Just-6-Beans/NASA-SPACER-Claude.git
cd NASA-SPACER-Claude
npm ci
npm run check    # type-check and tests
npm run dev      # then open http://127.0.0.1:5173/
```

In Windows PowerShell, use `npm.cmd` in place of `npm`. Then take a lane and start its branch:

```bash
git checkout -b lane/data        # or lane/rules, lane/experience
```

Write your name at the top of `notes/<lane>.md` and follow the working rules in [CHALLENGE.md](CHALLENGE.md#5-three-devices-three-lanes).

## Run it

Needs Node.js 20.19+ or 22.12+.

```bash
npm ci
npm run dev
```

Open **http://127.0.0.1:5173/**. Keep the terminal open while you play.

For co-op, run the service in a second terminal and keep it running too:

```bash
npm run server
```

It listens on `ws://127.0.0.1:2567`. To use another service, build or run with `VITE_COOP_URL=ws://host:port`. Solo play does not need the server.

Other commands:

| Command | What it does |
| --- | --- |
| `npm run build` | Type-check and build to `dist/` |
| `npm run preview` | Serve the built game at http://127.0.0.1:4173/ |
| `npm run check` | Type-check, then `npm test` |
| `npm test` | Mission rules, acceptance scenarios, and a live two-client co-op test |
| `npm run art` | Regenerate the SVG artwork |
| `npm run data:rovers` | Refresh the NASA snapshots, map tiles, pictures and videos for the rover expedition (needs internet). Add `-- --only=satellite,pictures` to run just some steps |

On Windows you can double-click `play.bat`. It installs dependencies if needed, starts the co-op service and the game, and opens the browser.

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Walk | WASD or arrow keys | On-screen d-pad |
| Jog | Hold Shift | ⇧ in the d-pad centre |
| Use nearest terminal | E (or click the terminal when close) | Orange E button |
| Close panel | Escape | Close button |
| Change spacecraft | ← / →, arrow buttons, wheel, swipe | Swipe |

HUD buttons: **Tasks** (Routine, Mission and Emergency list), **Sound**, **Debug** (FPS, collision boxes, both clocks, +250 visual-only sprites up to 3,000), **Co-op**.

On the rover screen, tap the map to place points for the rover to drive to. Use the zoom slider to look closer, and drag the map when zoomed in. While the rover drives, tap **Take photo** under its camera when the button lights up. On the **Rover parts** tab, tap the glowing dots to learn what each part does.

## Five-minute walkthrough

1. **Start mission** → choose a spacecraft → enter a call sign and pick a suit → **Launch** (or **Skip animation**).
2. You dock at the station. Walk up to **Payload**, just ahead of you. Pick an instrument and **Activate payload**. The relay faults.
3. Go to **Rover Comms** (rear right) and rotate the receiver segments to match the reference. **Confirm match**.
4. At **Power Grid** (rear left), raise Communications to at least 4. At 5, each signal leg is 2 minutes faster. Research at 3 or more makes rover drilling use 30 % less battery.
5. Optional: at **Calibration** (rear centre), tune gain and offset until both standards turn green so drilled samples are analysed. Optional routine tasks: battery balancing (driving draws 30 W less), cargo, water (+5 to the base score), medical.
6. Back at **Rover Comms**, open the planner. First you **choose your rover**: Perseverance in Jezero Crater or Curiosity in Gale Crater. Each card shows a real selfie, what that rover is good and not so good at, and a button to look at its parts. You keep the rover you choose for the whole mission.
7. **Tap the map** to place points. The rover drives them in order and the last point ⚑ is the spot it checks. Watch the battery and Mars-days forecast, then **▶ Start deployment**. The rover moves along your path while its camera plays a real drive film. When it drives into the ring around a camera mark, **Take photo** lights up: tap it to save a real NASA photo to your album and add to your score.
8. At the spot, **run tests** (Photograph, Weather, Radiation, Drill). Each uses some battery and fills in one bar. The big answer at the top says whether it is a good place, a risky place or a bad place. Then **Build the base here**, good or bad, or **Explore another spot**. When the battery gets low, **Recharge**: it takes real time, and the mission only lasts ten Mars days. Read the report and commission the habitat if your crew passed the medical check.

## Two-tab co-op

1. Run `npm run server` and `npm run dev`.
2. Open http://127.0.0.1:5173/ in two tabs or windows. Use different call signs and suits.
3. In each tab, after docking, press **Co-op** → **Join co-op room**, then close the panel.
4. Each tab shows the other astronaut, its name and its suit. Walk in one tab and watch the other.
5. Change power in one tab, for example Communications 3 → 4. The other tab's meters update immediately. Clocks, tasks, rover and landing stay per player.
6. A crewmate disappears while they are in the rover view or on the title screen, and reappears when they return. **Leave room** or closing the tab removes them.

If the service is offline, the Co-op panel says so and offers **Retry**. Solo play continues.

## Rover expedition (Perseverance and Curiosity)

**Choose your rover.** It is the first thing in the rover room, and the choice lasts the whole mission. Every pro and con on the cards comes from the numbers the game plays with.

| | Perseverance (Jezero Crater) | Curiosity (Gale Crater) |
| --- | --- | --- |
| Power source today | about 81 W | about 53 W |
| Reach on one charge, flat ground | about 1.6 km | about 1.2 km |
| Full recharge | about 1.1 Mars days | about 2.5 Mars days |
| Mass (climbing cost) | 1,025 kg | 899 kg |
| Where it starts | on a 7.3° slope, level enough for a base | on a 12.5° slope, too steep for a base |
| Crater roughness from orbit | 3.5 m | 4.1 m |
| Weather and radiation | borrowed from Curiosity's crater | measured in its own crater |
| Photo spots within 600 m of the start | 4 | 7 |
| Real stops on the map | 132 (tilt 0.9° to 20.7°) | 118 (tilt 3.2° to 24.0°) |

- **The map** is a 3 km square centred on where the real rover is. Its picture is real: the colour basemap of NASA's own "Where is the rover?" map, made from Mars Reconnaissance Orbiter HiRISE images (about 1.2 m per dot). A switch flips to a height map drawn from NASA's MOLA heights, with 20 m contour lines. The zoom slider goes to 6×; when zoomed in, drag the map, and it follows the rover while it drives. White dots are the places the rover really parked.
- **Battery:** one gauge, where 100 % is full and 0 % is NASA's safe-mode line (40 % of the real battery). Driving, tests and photos all use it. At 0 % the rover stops in safe mode until it is recharged.
- **Recharging:** when the gauge is at 50 % or less (or the rover cannot drive), a Recharge button appears. The rover parks while its nuclear power source refills the battery. The time is worked out from each rover's real power: what its MMRTG makes today minus a 30 W always-on load (our model).
- **Ten Mars days:** the mission lasts 10 sols. Driving counts at the real rover's top speed and recharging counts in full. When the days are used up, you build on a spot already visited or stay in orbit. The number 10 is a game rule, not a NASA figure.
- **Driving cost:** distance plus climb. Uphill costs more: the rover's mass times Mars gravity for every metre gained.
- **Photo spots:** camera marks on the map are places where the real rover took the photos saved in the game (16 per rover). Drive within 120 m of one and tap **Take photo** (20 Wh): its real photos join your album and each spot adds +2 to the base score, up to +10. The album strip under the camera and the **My photos** tab open them full size.
- **A spot's slope:** within 75 m of a real rover stop, the tilt NASA measured there. Anywhere else, the average slope from the MOLA grid (about 460 m), and the game says so.
- **Tests:** Photograph (80 Wh, about 6 % of the gauge) fills Level ground. Weather (40 Wh, 3 %) fills Sunlight and Warmth, once for the whole region. Radiation (40 Wh, 3 %) fills Low radiation, once for the region. Drill (300 Wh with IR-S1, 380 Wh with GPR-2, about 21 % or 26 %) fills Rock sample. A test you cannot afford says so on its button.
- **Verdict:** more than 10° is a bad place. Level ground with a site score of 60 or more is a good place; otherwise it is risky. Unmeasured bars score 0. You can build on any spot; the score and stars follow the verdict.
- **The camera:** while the rover drives it plays a real drive film made from the rover's own camera frames: Perseverance's sol 130 autonomous drive (NASA PIA24743) and Curiosity crossing the Dingo Gap dune (NASA PIA17938). The game lays moving grain, scan lines and labels over it so it looks like a signal coming in from Mars, and says so. The longer the drive, the longer it plays (about 22 m a second, from 8 to 70 seconds). When the rover is parked the camera shows a real photo taken at the nearest photographed stop, with the distance. Neither is your exact path, and the game says so.
- **Rover parts:** NASA's own 3D picture of each rover (an artist's concept, labelled as not a photo) with a dot on each part. The dots were placed by us and show roughly where each part is.
- **Learn tab:** a JPL video about each rover, the drive film, the real selfie and links to NASA pages.
- **Real (NASA):** rover positions, tilts and elevations ([Perseverance](https://mars.nasa.gov/mmgis-maps/M20/Layers/json/M20_waypoints.json), [Curiosity](https://mars.nasa.gov/mmgis-maps/MSL/Layers/json/MSL_waypoints.json)); the orbital map tiles behind NASA's location maps ([Perseverance](https://science.nasa.gov/mission/mars-2020-perseverance/location-map/), [Curiosity](https://science.nasa.gov/mission/msl-curiosity/location-map/)); raw images taken inside the map ([Perseverance](https://mars.nasa.gov/mars2020/multimedia/raw-images/), [Curiosity](https://mars.nasa.gov/msl/multimedia/raw-images/)); map heights (MOLA gridded topography, NASA PDS); sunrise, sunset and temperatures at Gale (Curiosity REMS); radiation at Gale (Curiosity RAD via RadLab, May 2024); terrain roughness (MOLA); MMRTG 110 W at launch with 4.8 %/year decay; Perseverance battery 2,408 Wh and the 40 % rule; driving under 200 W; top speeds 152 and 144 m/h; rover masses 1,025 and 899 kg; the length of a Mars day; two real selfies (PIA26344, PIA24543), two artist's concepts (PIA22105, PIA14760), two JPL videos and two real drive films from the [NASA Image and Video Library](https://images.nasa.gov/) and Photojournal.
- **Our model:** a 30 W base load, the battery each test and photo uses, the Curiosity battery's watt-hours (from 2 × 42 Ah at Perseverance's ratio), recharge times, the ten-day limit, the photo bonus, the bar scores, the rock-sample bar, the 10° limit and the stars. Weather and radiation come from Gale and stand in for Jezero too.
- **NASA Eyes:** with Curiosity, the **Learn** tab can load NASA's [Experience Curiosity](https://eyes.nasa.gov/apps/curiosity/) 3D app. It needs internet, as does **Load newest photos**. Everything else runs offline from `data/nasa/` and `public/nasa/` (about 56 MB: 26 MB of map tiles, plus the photos, videos and drive films), refreshed with `npm run data:rovers`.

## Station rules in brief

| Ship | Payload | Budget | Rover battery | One-way relay |
| --- | ---: | ---: | ---: | ---: |
| Odyssey | 18 kg | 100 cr | 100% | 8 min |
| Atlas | 25 kg | 113 cr | 92% | 8 min |
| Vector | 12 kg | 88 cr | 100% | 7 min |

- **Instruments:** IR-S1 costs 42 cr and weighs 7 kg; the rover's drill draws 160 W with it. GPR-2 costs 68 cr and weighs 13 kg; drilling draws 200 W.

## Acceptance scenarios (verified by `npm test` and in the browser)

1. Place two points and deploy: the rover stops at the last point, which becomes spot B, and the forecast matches what happened.
2. At a flat real stop, all four tests with a calibrated instrument give a good place.
3. A steep real stop is a bad place, and the base can still be built there for one star.
4. A drive longer than the battery ends in safe mode partway. Recharging ends safe mode, refills the battery and uses up Mars days (about 2.5 for Curiosity, about 1.1 for Perseverance).
5. Station choices change the rover: ship charge, battery balancing, research power, the water purifier, and Communications ≥ 4 to deploy.
6. Curiosity at Gale plays the same way.
7. One rover for the whole mission: a second choice is refused, and each rover's pros and cons match the numbers.
8. Ten Mars days: driving and recharging use them up, a drive must fit in the time left, and when they run out the base can still be built on a visited spot.
9. A real photo spot in reach joins the album, costs 20 Wh and adds +2 to the score (at most +10); one out of reach or already taken is refused.
10. Two tabs: both astronauts appear and move, power syncs, avatars hide and reappear, and solo works with the server offline.

## Project layout

- `src/core/`: pure TypeScript rules (data, power, tasks, mission, co-op protocol validation, `survey.ts` for the map, driving, tests and site scores, `rovers.ts` for rover facts and parts). This code is shared with the server and tests.
- `src/game/`: Phaser scenes (station and Mars) and input.
- `src/ui/`: title, fleet, crew, launch, task panels, rover operations (`roverView.ts`, `roverPanels.ts`, `mapView.ts`), and the report.
- `server/`: the Colyseus `spacer_power` room.
- `scripts/`: the art generator and `fetch-rover-data.mjs` (NASA snapshots). `test/` holds the tests.
- `data/nasa/` and `public/nasa/`: the saved NASA data, orbital map tiles, rover pictures, raw images and videos.
