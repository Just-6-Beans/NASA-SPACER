# SPACER

An educational browser game about orbital station operations and a delayed Mars rover survey, inspired by the NASA Space Apps Challenge. You pick a spacecraft, crew the station, prepare a rover, repair a relay, send a Mars survey plan across the light-speed delay, wait for evidence, and decide whether and where to land.

**The scenario is simulated.** Terrain, ice readings, timing, costs and the station orbit are game rules, not NASA data. No NASA data or branding is used.

Stack: Phaser 3.90 (Arcade Physics), TypeScript, Vite, HTML/CSS interface, Colyseus co-op. All art is original vector artwork generated by `scripts/gen-art.mjs` and bundled in `public/assets/`.

This is our team's entry for the NASA Space Apps Challenge 2026 challenge [Space Mission Design Game](https://www.spaceappschallenge.org/2026/challenges/space-mission-design-game/). It is a fresh build of Spacer. The original prototype is in [Space-Mission-Design-Game](https://github.com/Just-6-Beans/Space-Mission-Design-Game).

## Set up a device

```bash
git clone https://github.com/Just-6-Beans/NASA-SPACER-Claude.git
cd NASA-SPACER-Claude
npm ci
npm run check    # type-check and tests
npm run dev      # then open http://127.0.0.1:5173/
```

In Windows PowerShell, use `npm.cmd` in place of `npm`. Then take a lane and start its branch:

```bash
git checkout -b lane/data        # or lane/rules, lane/experience
```

Write your name at the top of `notes/<lane>.md` and follow the working rules in [CHALLENGE.md](CHALLENGE.md#5-three-devices-three-lanes).

## Run it

Needs Node.js 20.19+ or 22.12+.

```bash
npm ci
npm run dev
```

Open **http://127.0.0.1:5173/**. Keep the terminal open while you play.

For co-op, run the service in a second terminal and keep it running too:

```bash
npm run server
```

It listens on `ws://127.0.0.1:2567`. To use another service, build or run with `VITE_COOP_URL=ws://host:port`. Solo play does not need the server.

Other commands:

| Command | What it does |
| --- | --- |
| `npm run build` | Type-check and build to `dist/` |
| `npm run preview` | Serve the built game at http://127.0.0.1:4173/ |
| `npm run check` | Type-check, then `npm test` |
| `npm test` | Mission rules, acceptance scenarios, and a live two-client co-op test |
| `npm run art` | Regenerate the SVG artwork |

On Windows you can double-click `play.bat`. It installs dependencies if needed, starts the co-op service and the game, and opens the browser.

HUD buttons: **Tasks** (Routine, Mission and Emergency list), **Guide** (floor chevrons to the next objective, on by default), **Sound**, **Debug** (FPS, collision boxes, both clocks, +250 visual-only sprites up to 3,000), **Co-op**. The deck map in the corner shows the three nodes, you, your crewmate and the next objective.

On the rover map, drag to pan, use the wheel or pinch to zoom, or use + / − / Fit.

## Five-minute walkthrough

1. **Start mission** → choose a spacecraft → enter a call sign and pick a suit → **Launch** (or **Skip animation**).
2. You arrive through the airlock in node B. Follow the floor guide past the rover to the **Mission Ops** table under the cupola and read the brief. Then go to **Payload** in the rover bay, pick an instrument and **Activate payload**. The instrument appears on the rover, and the relay faults.
3. Go to **Rover Comms** (node C, rear right) and rotate the receiver segments to match the reference. **Confirm match**.
4. At **Power Grid** (node A, rear left), raise Communications to at least 4. At 5, each signal leg is 2 minutes faster. Research at 3 or more cuts uncertainty instead. The buses in the floor light up with what you route.
5. Optional: at **Calibration** (node C, front right), tune gain and offset until both standards turn green. Optional routine tasks: battery balancing, cargo, water, medical. **Mission Ops → Mission status** shows what each choice is doing to the forecast.
6. Back at **Rover Comms**, open the planner. Choose a route and a scan, queue Drive → Scan → Return, read the forecast, and **Transmit sequence**.
7. Advance the clock with **Next event**, **+5 min** or **Run clock**. Evidence counts only once it reaches Earth.
8. **Review landing sites**: select a site and **Confirm site**, or defer. Read the report and commission the habitat if your crew passed the medical check. Then **Replay with this crew** or **Return to title**.

## The station

Three pressurised nodes in a row, joined by open hatches. You can walk behind the freestanding consoles.

| Node | Rear wall | Front |
| --- | --- | --- |
| **A · Utility** | Power Grid, beside the power core. Your ship is docked outside the window. | Hab Systems: water, hydroponics, medical |
| **B · Command** | The cupola, with the Mission Ops holo-table in front of it | The rover bay (Payload) and the airlock you arrive through |
| **C · Science & Comms** | Rover Comms. The relay dish is outside the window. | The Calibration bench |

The deck shows mission state, so you can read your choices off the room:

- **Power buses** in the floor run from the Power Grid to Hab Systems (life support), Rover Comms (communications) and the Calibration bench (research). Each glows with the units routed to it, and turns amber while it is below what transmission needs.
- **Consoles** show live values: the allocation on the Power Grid, the one-way signal delay on Rover Comms, the rover's starting charge in the bay, and lamps for calibration, water and medical.
- **Relay fault**: the beacon flashes, the dish hunts for the carrier, and the link display reads NO LINK until you repair it.
- **Mission Ops** has three tabs: the mission brief, a live mission status (budget, mass, power, battery and time against their limits, then each choice and what it is causing), and the data sources for every number.

## Two-tab co-op

1. Run `npm run server` and `npm run dev`.
2. Open http://127.0.0.1:5173/ in two tabs or windows. Use different call signs and suits.
3. In each tab, after docking, press **Co-op** → **Join co-op room**, then close the panel.
4. Each tab shows the other astronaut, its name and its suit. Walk in one tab and watch the other.
5. Change power in one tab, for example Communications 3 → 4. The other tab's meters update immediately. Clocks, tasks, rover and landing stay per player.
6. A crewmate disappears while they are in the rover view or on the title screen, and reappears when they return. **Leave room** or closing the tab removes them.

If the service is offline, the Co-op panel says so and offers **Retry**. Solo play continues.

## Simulated rules in brief

| Ship | Payload | Budget | Rover battery | One-way relay |
| --- | ---: | ---: | ---: | ---: |
| Odyssey | 18 kg | 100 cr | 100% | 8 min |
| Atlas | 25 kg | 113 cr | 92% | 8 min |
| Vector | 12 kg | 88 cr | 100% | 7 min |

- **Instruments:** IR-S1 costs 42 cr and weighs 7 kg, with a quick-scan draw of 6 points and ±19 uncertainty. GPR-2 costs 68 cr and weighs 13 kg, with a draw of 14 points and ±11 uncertainty.
- **Routes:** Ridge bypass takes 16 min and 25 points per driving leg. Basin shortcut takes 10 min and 36 points per leg.
- **Scans:** a deep scan takes 8 min instead of 4, uses 8 extra points, and cuts uncertainty by 7.
- **Rover reserve:** the battery floor is 20%. A command that would cross it runs only partway, then the rover enters safe mode.
- **Ice reading:** the estimate is 31%. Calibration cuts uncertainty by 5; skipping it adds 9. Research filtering cuts 4. Minimum uncertainty is ±3. Evidence is strong when the low end is 22% or more.
- **Dust deadline:** Ares Shelf closes at T+54.
- **Meridian Plain:** needs 26 cr of water plus a 12 cr power kit. The water task saves 8 cr; the cargo task adds 5 cr to your budget.

## Acceptance scenarios (verified by `npm test` and in the browser)

1. Odyssey, calibrated IR, power 3/5/2, ridge, deep scan. The scan arrives at T+36 as 31 ±7%, the rover ends at 36%, and final telemetry arrives at T+52, so Ares Shelf clears. With battery balancing the rover ends at 42%.
2. Odyssey, calibrated IR, power 3/4/3, ridge, deep scan. The evidence is strong, but final telemetry at T+56 means Ares Shelf has closed.
3. Odyssey, uncalibrated GPR, basin, quick sweep. The scan completes, the return stops at 20% in safe mode, and the reading is weak. Meridian's 38 cr is more than the 32 cr left; the water task brings it to 30 cr, which you can afford.
4. Two tabs: both astronauts appear and move, power syncs, avatars hide and reappear, and solo works with the server offline.

## Project layout

- `src/core/`: pure TypeScript rules (data, power, tasks, rover simulation, mission, co-op protocol validation). This code is shared with the server and tests.
- `src/art/geo.json`: station and Mars geometry, read by both the art generator and the game. `src/game/deck.ts` is its typed view.
- `src/game/`: Phaser scenes (station and Mars), input, the live station layer (`stationFx.ts`), and deck pathfinding for the floor guide (`nav.ts`).
- `src/ui/`: title, fleet, crew, launch, task panels, Mission Ops, the station HUD and deck map, rover operations, landing sites, and the report.
- `server/`: the Colyseus `spacer_power` room.
- `scripts/`: the art generator. `test/` holds the tests.
